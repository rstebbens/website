# Website draft

Generated from the **PUBLISHED** Google Sites Takeout export, retaining the existing GitHub theme CSS.

This is a first-pass content migration, not a final visual QA. 21 pages and exported images included. Embedded widgets may need individual replacement.

For local preview run `python -m http.server 8000` from this folder, then open http://localhost:8000. Root-relative paths expect hosting at domain root. To deploy to a GitHub Pages project subpath `/website/`, adjust asset and internal URLs or use a staging domain.
